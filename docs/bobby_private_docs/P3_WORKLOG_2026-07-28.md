## 一、实际完成项

### 1) 生命周期联调测试

文件：`demo1/src/test/java/com/example/demo/service/PaymentLifecycleIntegrationTest.java`

覆盖内容：
- 创建支付后历史应仅 1 条（`null -> CREATED`）
- 处理成功后历史应 4 条（`CREATED -> VALIDATED -> SENT -> COMPLETED`）
- `fromStatus` 链路连续性检查
- `triggeredBy` 检查（创建 USER，后续 SYSTEM）
- 历史时间升序检查（`changedAt`）
- 幂等重放不新增历史
- 列表查询与按状态筛选基本联调

### 2) Controller 联调测试

文件：`demo1/src/test/java/com/example/demo/controller/PaymentControllerIntegrationTest.java`

覆盖内容：
- 创建接口返回 `201 + Location`
- 相同幂等键重放返回 `200` 且同 ID
- 详情查询可取回已创建支付
- 列表查询与状态筛选
- 处理接口返回 `COMPLETED`
- 历史接口返回 4 条升序记录
- 创建 -> 处理 -> 详情 -> 历史端到端一致性

> 说明：当前项目测试依赖下 `AutoConfigureMockMvc` 不可用，

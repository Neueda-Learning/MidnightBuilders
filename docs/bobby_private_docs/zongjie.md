### 1. 你做了生命周期联调测试
你写了：

- `PaymentLifecycleIntegrationTest`

重点验证：

- 创建支付后是不是只有 1 条历史
- 处理成功后是不是有 4 条历史
- 状态是不是按 `CREATED -> VALIDATED -> SENT -> COMPLETED` 走

- 幂等重放会不会错误地重复写历史

这部分很重要，因为它直接证明“状态变化 + 历史审计”这条线是真的通的。
